# 庭院自由视角防透明

使用游戏自带的恶魔庭院自由视角时，靠近恶魔也能保持可见。

[English](README.md) · [下载安装包](https://github.com/0smium/game-mods/releases/download/smtvv-v1.0.0-rc1-r2/SMTVV-GardenFreecamVisibility-1.0.0-rc1-r2.zip)

## 安装

适用于 Windows Steam 版。关闭游戏，把包内 `Project` 文件夹解压到游戏目录。如果没有 ASI 加载器，再将 `Optional-ASI-Loader/dsound.dll` 复制到 `Project/Binaries/Win64`；已有加载器则沿用。之后从 Steam 正常启动。

[详细安装与卸载](../../../docs/install.zh-CN.md)

## 使用

进入恶魔庭院，开启游戏自带的自由视角即可。**无需按键，无需配置。** 本模组只修复透明问题，不提供新的自由摄像机。

可以单独使用，也可以搭配[第一人称模组](../first-person/README.zh-CN.md)。
