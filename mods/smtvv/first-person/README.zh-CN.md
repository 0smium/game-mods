# SMTVV 第一人称

用第一人称探索地图，自由调整眼高、FOV 和晃动。贴近庭院恶魔时保持可见，并修复紫色形态冲刺特效挡镜头的问题。

[English](README.md) · [下载安装包](https://github.com/0smium/game-mods/releases/download/smtvv-v1.0.0-rc1/SMTVV-FirstPerson-1.0.0-rc1.zip)

## 安装

适用于 Windows Steam 版。关闭游戏，把包内 `Project` 文件夹解压到游戏目录。如果没有 ASI 加载器，再将 `Optional-ASI-Loader/dsound.dll` 复制到 `Project/Binaries/Win64`；已有加载器则沿用。之后从 Steam 正常启动。

[详细安装与卸载](../../../docs/install.zh-CN.md)

## 操作

启动后默认开启第一人称。**F3** 开关，切换地图后保留本次选择。

| 按键 | 调整 | 默认值 |
| --- | --- | --- |
| F4 | 眼高增加 1 cm | 偏移 +40 cm |
| F5 | FOV 增加 1° | 110° |
| F6 | 晃动增加 0.25 cm | 5 cm |

按住 **Shift** 反向调整，按住 **Ctrl** 加大步幅，同时按住两者则大步减少。**Ctrl+F3** 恢复三项默认值。晃动调到 0 即可关闭，修改自动保存。

本模组用于探索视角。游戏自带的庭院自由视角请搭配[独立防透明模组](../garden-freecam-visibility/README.zh-CN.md)。
